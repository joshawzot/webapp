Advanced Combine

Configure advanced row-wise combining for selected tables

How it works: Each table will contribute rows based on the values you specify. If you have 2 tables with values "1,2,3,4" and "5,6,7,8", the combined table will have:
  • First 1 row from table1, then first 5 rows from table2
  • Next 2 rows from table1, then next 6 rows from table2
  • Next 3 rows from table1, then next 7 rows from table2
  • Next 4 rows from table1, then next 8 rows from table2
Total rows: 1+5+2+6+3+7+4+8 = 36 rows
This determines how many values you'll assign to each table.
